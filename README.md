# Life Tracker

Your habits. Your plan. One day at a time.

## Download & install on Android

**[Download Life Tracker APK](https://github.com/MRNOWSHIRWAN/life-tracker/releases/download/v1.1.1/Life-Tracker-Friends.apk)**

Android 8.0 or newer. No GitHub login needed to download.

1. Open the **Download Life Tracker APK** link above in Chrome and tap Download if asked.
2. When the download finishes, tap it. Or open **Files > Downloads > Life-Tracker-Friends.apk**.
3. If Android asks, enable **Allow from this source / Install unknown apps** for Chrome or your Files app.
4. Tap **Install**, then **Open**. Turn that source's install permission off afterward.
5. Enter your name. You can change it anytime in **Profile**.
6. Open **Habits** to add your habits. Open **Plan** to write your own goals, timetable and weekly routine.

No renaming, HTML copying, app builder or Play Store needed.

This APK is development-signed. A browser may ask you to confirm downloading an APK. Do not disable Play Protect or bypass a harmful-app block. If installation fails, keep the error message and ask for help.

## What's inside

- Blank habits and plan, ready for your own routine
- Editable welcome name
- Daily motivation: 60 built-in lines rotating offline, not editable (repeats after 60 days)
- Check-ins, contribution squares, streaks, reflections and dark/light mode
- JSON backup export/restore

The app works locally. No Internet permission, ads, analytics, online login, cloud sync or background reminders. Phone and tablet progress are separate.

## Keep your progress safe

Use **Backup > Download JSON backup** regularly, especially before uninstalling or clearing app data. Restore your JSON through **Backup > Restore**. If updating an existing installation, install the new APK over it instead of uninstalling first.
